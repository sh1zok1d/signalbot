# PROJECT_CLOSURE_DECISION_V1 — Pulsy (Signalbot) закрывается окончательно

**Статус:** решение владельца от 2026-10-15, оформлено в этом документе; вступает в силу при слиянии ветки `claude/pulsy-closure-yerlly` в `main` (отдельное разрешение владельца). До слияния — подготовленный документ. Все остальные документы закрытия лежат в `docs/closure/` и подчинены этому.

**Режим проекта с момента вступления:** `CLOSED / ARCHIVE_ONLY / NO_RESEARCH / NO_PRODUCT / NO_RESTART`.

---

## 1. Решение

1. Pulsy (ранее Signalbot) закрывается окончательно как продукт, как исследовательская программа и как сервис. Цель — завершить проект, а не оставить задел для перезапуска.
2. Новых Forecast Engine, Signal Engine, гипотез, исследовательских юнитов, прогнозных экспериментов и продуктовых направлений не будет. Ни один закрытый юнит не переоткрывается, ни одна ячейка открытой границы атласа не исследуется.
3. Сохраняются: код, научные результаты, технические достижения, история проекта и все записи — без правок задним числом.
4. Holdout `E1-RUN-001` `[2026-08-16T00:00Z, 2026-08-25T17:20Z)` **не открывается**. Эксперимент `E1-RUN-001` закрывается как технически незавершённый без исполнения; замороженный одношаговый оценщик не запускается никогда. Это решение владельца, а не вывод из данных.
5. Оригинальный репозиторий остаётся приватным. Публичная публикация **не разрешена**; для неё подготовлено отдельное предложение (`docs/closure/PUBLIC_RELEASE_PROPOSAL_V1.md`), требующее отдельного разрешения.
6. Приоритет операционного закрытия — сохранение результатов: резервные копии VPS, баз, прогнозов, журналов, конфигураций и научных артефактов с проверкой целостности и восстановления, **до** любого необратимого действия.
7. До отдельного разрешения владельца не выполняется ни одно необратимое действие: VPS не останавливается, ключи не отзываются, данные не удаляются, репозиторий не открывается, merge в `main` не делается.

## 2. Основания

Решение опирается на записи проекта, а не пересказывает их. Ключевые:

- `docs/PULSY_INDEPENDENT_FORECAST_INVESTIGATION_2026-10-14.md` и `docs/PULSY_FORECAST_INVESTIGATION_REVISION_2026-10-14.md`: направление на 1h–4h по свечным данным — AUC 0,54–0,55 при издержках выше валовой ценности; V1 как направление — анти-предиктор; механизмы V2 опровергнуты в масштабе; предсказуема только волатильность (R² 0,5–0,7).
- `docs/PULSY_CROSS_MARKET_STUDY_2026-10-14.md`, `docs/PULSY_CROSS_MARKET_REVISION_2026-10-14.md`: межрыночная информация ≤ +0,005 AUC; кросс-секционный разворот ниже порога безубыточности ≈ 1 б.п.
- `docs/PULSY_SIGNAL_ENGINE_AUDIT_2026-10-15.md`: Level Engine — одно явление расширения волатильности без направления; межбиржевые признаки не добавляют информации; все торгуемые выражения с нулевой или отрицательной валовой ценностью; парные когорты отобраны по пути.
- `docs/closure/RESEARCH_CATALOG_FINAL_V1.md`: 207 зарегистрированных юнитов атласа (около 80 дошли до чтения исхода, остальные закрыты раньше по методу, данным или информации), из них `CONFIRMED` — один контекстный объект (D7), валидированных торговых edge — 0.
- Оценка владельца продукта (2026-10-15): в бете нет причин платить даже владельцу; пользователей с описанной болью, под которых можно переделать продукт, нет.

Закрытие не оправдывается и не приукрашивается: результаты говорят сами за себя (`docs/closure/PUBLIC_SUMMARY_RU.md`, `PUBLIC_SUMMARY_EN.md`).

## 6. Разрешения, которые требуются отдельно

Каждое — отдельным сообщением владельца, после выполнения предыдущих шагов плана:

1. merge ветки `claude/pulsy-closure-yerlly` в `main` (вступление решения в силу);
2. выполнение резервного копирования на VPS и проверка восстановления (не необратимо, но требует доступа);
3. остановка сервисов и таймеров, затем VPS;
4. отзыв токена Telegram-бота и API-ключей, закрытие платных ресурсов;
5. удаление или анонимизация персональных данных участников в соответствии с `PAID_RESOURCES_AND_PII_V1` §3;
6. создание публичной очищенной версии и её открытие (если будет решено).

## 7. Что это решение не делает

Не удаляет ветки, не переписывает историю git, не меняет semantics замороженных экспериментов, не объявляет никакой результат ошибочным. Оно фиксирует конец работы.
