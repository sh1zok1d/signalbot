## 2. Перечень действий владельца

1. Принять документы; дать П1 (merge).
2. Заполнить приватную заметку (этап 1); ответить себе на вопрос §3.5: есть ли основание хранить полный архив с персональными данными после закрытия (по умолчанию — нет).
3. Создать пароль архива: файл root 0600 на VPS и запись в менеджере паролей. Дать П2; выполнить `closure_backup.sh` (dry-run, `--apply`), копии наружу, `closure_restore_verify.sh` на своём компьютере; записать `BACKUP_MANIFEST`.
4. Дать П3; выполнить чек-лист S0–S4 (таймеры приложения, сервисы, финальный зашифрованный дамп с проверкой).
5. Дать П4 с явной формулировкой: «оснований хранить полный архив нет — уничтожить после проверки обезличенного» или «основание …, срок …, дата уничтожения …». Выполнить S5–S7.
6. Выполнить S8 (контейнеры, копия volumes).
7. Дать П5; выполнить S9.
8. Дать П6; выполнить S10 и §3.5 (уничтожение копий с персональными данными: закрывающий полный архив, локальные дампы, off-site тиры с очисткой корзины, снапшоты, свои копии, Telegram-чат).
9. Финальный коммит, mirror, архивация (S11).
10. Решить о публичной версии (П7) отдельно, без спешки; до решения публикация запрещена.
11. Контроль через 35 дней (этап 14).
